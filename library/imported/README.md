# Importados

Coloque aqui `.md` com frontmatter YAML (opcional):

```yaml
---
title: Título
category: estrategias
tags: tag1, tag2
updated: 2026-10-29
---
```

Arquivos entram no catálogo v2 automaticamente (sem editar `index.json`).

Importação em lote: ZIP via painel **Importar ZIP** (camada curada) ou copie arquivos manualmente nesta pasta.
